# 化险为夷 · 化工安全连连看

> 一款把化工安全知识嵌进「连连看」通关机制里的纯前端网页小游戏。
> 认标志、辨危化品、处置泄漏——连对了才通关，连错了要扣时间。

**在线试玩**：<https://9ns8q4695h-dot.github.io/chem-safety-match/>

> 已用 GitHub Pages 部署（仓库：<https://github.com/9ns8q4695h-dot/chem-safety-match>，公开）。若链接失效，可按文末「运行与部署」自行重新发布。

- 安全领域：化工安全（危化品 / 安全标识 / 应急处置）
- 玩法类型：连连看（配对消除），中难度
- 技术栈：原生 HTML + CSS + JavaScript，零依赖、零后端、零外部素材
- 适配：桌面浏览器 + 手机浏览器（竖屏 / 横屏）

## 一、玩法说明

### 1. 核心规则

棋盘上有 20 张卡片，两两成对：**A 面**是安全标识图形或危化品名称，**B 面**是它的含义或正确处置措施。

1. 依次点击两张卡，若它们**属于同一对**、且**能用不超过 2 个折角的通路连起来**，即配对成功；
2. 通路被其他卡挡住时，点第二张只会提示「被挡住了」，**不扣分**；
3. 点错对（两张不是一对）会 **扣 10 分、倒扣 3 秒、连击中断**；
4. 每消除一对，就弹出一张**知识卡**（含判定要点与依据），收录进「图鉴」；
5. 清空全部卡片即通关；时间耗尽则失败，可重开。

### 2. 三个关卡

| 关卡 | 主题 | 内容 | 限时 |
| --- | --- | --- | --- |
| 第 1 关 | 标识识别 | 10 个 GB 2894 安全标志 ↔ 含义 | 150 s |
| 第 2 关 | 应急处置 | 10 种危化品 ↔ 现场第一反应 | 180 s |
| 第 3 关 | 储存与作业 | 气瓶、动火、混存、SDS、有限空间等 ↔ 制度要求 | 210 s |

第 1 关通关后解锁下一关；成绩与已收集知识会存进浏览器本地（`localStorage`），可随时从「图鉴」复习。

### 3. 计分与评级

- 配对成功：**100 分 + 连击加成**（每连击 +20，单次封顶 +100）；
- 错误配对：**−10 分、−3 秒**；
- 提示：每关 3 次，每次 **−15 分**（高亮一对可消卡片）；
- 洗牌：每关 2 次，每次 **−10 分**；无解时自动免费洗牌；
- 通关奖励：**剩余秒数 × 2**，零失误再 **+200**；
- 评级：零失误且剩余时间 ≥35% → **S**；错误 ≤1 次 → **A**；≤3 次 → **B**；其余 → **C**。

### 4. 交互细节

- 键盘：`Esc` / `P` 暂停；暂停、切后台会自动冻结倒计时；
- 手机：整块棋盘自适应缩放，卡片可点按，横屏也可玩；
- 音效：Web Audio 实时合成（点击、配对、错误、通关），**无任何外部音频文件**，可一键静音；
- 知识卡 7 秒自动收起，也可点右上角关闭；**知识卡展示期间倒计时暂停**，读知识不占时间；
- 每成功配对一对，该条知识就立即收录进「图鉴」（不必等通关）。

## 二、技术实现

### 1. 技术栈

| 层 | 方案 | 说明 |
| --- | --- | --- |
| 页面 | 原生 HTML | 根目录 `index.html`，双击即可打开 |
| 样式 | 原生 CSS（CSS Grid + 变量） | 暗色工业风；响应式断点 760 / 640 / 460 px |
| 逻辑 | 原生 JavaScript（ES5 风格，传统 `<script>`） | 不用构建工具、不用框架 |
| 寻路 | BFS（状态 = 行、列、方向、折角数） | 0/1/2 折角判定，棋盘外加一圈虚拟边界 |
| 图形 | 内联 SVG 自绘 | 10 个安全标志，无版权风险 |
| 音效 | Web Audio API 合成 | 无外部素材 |
| 存储 | `localStorage` | 键名 `huaxianweiyi.save.v1`，读写有 try/catch 兜底 |

**为什么不用 React / 不用 ES Module？** 作业要求「双击 index.html 即可本地打开」。`file://` 协议下浏览器会拦截 ES Module 的跨源加载，所以全部脚本用传统 `<script>` 按顺序加载；也刻意不引入任何 CDN 依赖，断网也能玩。

- **转引**（只见到转载/摘要，未读标准正文）：GB 30871-2022 第 5.2.13、5.3.2 条文字；GB 9448-2025 第 11.5.5 条；GB 11984-2024 中「上风向、高处撤离」对应条款；GB 2894-2025 四类标志几何形状条款（形状描述取自 2008 版及官方科普口径）；GB/T 50720 第 6.3.3 条。
- **不作为标准的表述**：「五双」是治安/企业管理要求，非国标条款；「冲洗 15 分钟」是通用急救建议，非 GBZ 54 条款；泄漏处置四项原则无单一强制条款可整句引用。
- **未核实项**已在核查报告末尾单独列出，游戏文案没有把「未核实」内容包装成「标准原文」。

### 3. 三个「绝对不能错」的判定

1. **油锅/电石/金属钠遇水**：电石、钠遇水放热并生成可燃气体，着火时**禁用水、泡沫、四氯化碳**，只能用干砂、干粉、CO₂；浓硫酸稀释只能**酸入水**。
2. **有限空间**：必须**先通风、再检测、后作业**；事故后**严禁盲目施救**（应急管理部令第 13 号第十五条）。
3. **触电急救**：先**切断电源**或用干燥绝缘物使触电者脱离电源，**不可徒手拉拽**。

## 四、AI 参与与核查

本项目全程使用 AI 编程助手（DeepSeek Harness 中的 deepseek-flash 模型）辅助完成：需求拆解、代码骨架、知识条目初稿、测试脚本、文档草稿。

- **AI 不负责「拍板」安全结论**：知识条目初稿由 AI 生成，再由独立的核查流程逐条回查标准/官方来源，修正后才写进代码；
- **AI 生成的代码必须跑测试**：`tests/validate.js`（数据 + 寻路 + 整关模拟）与 jsdom 冒烟测试（22 项）均通过后才保留；
- **已记录的 AI 错误**：标准号过期（GB 2894-2008 → GB 2894-2025 等 4 处）、条款张冠李戴（GB 9448 的 5 m/10 m）、伪引用（把「15 分钟」归到 GBZ 54）、B 面文案溢出、`unlocked` 字段语义误读等，详见 [AI使用记录.md](AI使用记录.md)。

## 七、已知限制与后续计划
